# Optimization history

The user requires every optimization to be recorded for future work.

For each optimization in this game:
- Add a dated version entry to `docs/优化日志.md` describing the original problem, concrete changes, relevant timing/behavior changes, checks actually run, remaining limits, and useful next steps.
- Update `docs/验证记录.md` with verification evidence and link representative screenshots/previews when useful.
- Preserve earlier entries; mark later corrections explicitly instead of rewriting history.
- Keep README links current and include the documentation in the same source revision as the implementation.
- Do not claim tests, review, deployment, or improvements that have not been verified.
