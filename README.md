# 神火猎记

《怪物猎人 崛起》启发的单人横版像素动作原型。浏览器即开即玩，支持键盘和触屏。

## 运行

需要 Python 3，测试需要 Node.js 20 或更高。没有第三方运行时依赖。

```sh
npm run dev
```

访问 http://localhost:4173。也可在项目目录运行 `python3 -m http.server 4173 --directory dist`。请通过 HTTP 服务打开，不要直接双击 index.html（浏览器会限制 ES module 加载）。

```sh
npm test
```

## 内容

- 男女猎人外观、命名与编辑。
- 14 类简化武器，各有普攻、2 个技能和终极技；武器伤害、速度、距离及远程弹体不同。
- 镰鼬龙王 / 青熊兽 / 雌火龙；废神社 / 寒冷群岛 / 熔岩洞三个横版竞技场。
- 移动、跳跃、闪避、回复药、怪物预警与愤怒、技能输入缓冲。
- 随机素材、金钱、任务解锁、独立武器强化、共享护甲强化。
- 当前浏览器自动存档、JSON 导入导出；失焦自动暂停。

## 操作

A / D 或左右方向键移动；空格跳跃；J 普攻；K / L 小技能；U 大招；Shift 闪避；H 回复药；Esc 暂停。命中积攒气势，100 气势释放大招。持续按住 J 时可以插入技能，技能将排队到普攻冷却结束。触屏使用画面下方按钮，支持同时移动与攻击。

从“出发狩猎”开始会先创建角色。赢得首场后可回村强化并解锁第二个任务。失败或主动离开不发放奖励。技能要在正确距离与朝向释放。

## 当前范围

v0.1 为可玩原型。角色、怪物和场景为程序绘制的像素化演绎，尚非精细逐帧精灵。14 类武器共用简化动作框架，未实现原作各武器的完整资源系统与连段。无联机、捕获、部位破坏或复杂配装。平板完成了 768×1024 响应式检查，真实触屏设备的多点触控和性能仍需实机验证。

游戏数据保存在当前域名和浏览器中；localhost、127.0.0.1 与在线站点的存档互不共享，请导出并导入迁移。损坏存档在新存档首次保存前尝试保留到同名 recovery 键。

本项目是 CAPCOM《怪物猎人》的非官方同人原型。

## v0.2 动作与打击感（2026-10-19）

猎人采用关节驱动的跑步、空中姿态、落地缓冲和翻滚；围巾有跟随摆动。轻武器交替挥斩，重武器较长起手，长柄武器突刺，远程武器射击后坐。攻击按起手、有效挥击、收招播放，伤害或弹丸在有效挥击阶段触发。技能位移改为连续突进，翻滚可以取消尚未命中的攻击，已花费的技能冷却仍保留。

三只怪物增加尾巴、头部、腿、爪和翅膀的分部件动作；预警蓄势、冲撞、收招和受击姿态都有变化。命中增加 35–85 ms 短暂停顿、火花、受击后仰与方向正确的刀光，起跳、落地、翻滚增加扬尘。系统开启“减少动态效果”时关闭镜头震动。胜利奖励即时保存，倒地动画结束后展示结算。

参考：
- [Supergiant 官方 Hades 更新说明](https://www.supergiantgames.com/blog/hades-superstar-update-patch-notes/)中的攻击时序、输入缓冲与不同武器动画优化。
- [Dead Cells 主设计师访谈](https://arstechnica.com/video/watch/dead-cells-how-to-avoid-falling-to-your-death-war-stories/?c=series)所强调的操作响应与容错方向。

这是针对当前像素原型的程序动画改进，未复制上述游戏的素材、动画帧或数值。现阶段仍采用四类武器动作家族，尚非每种武器独立手绘逐帧动画。存档格式和按键不变。

## v0.3 跳跃与技能姿态（2026-10-19）

- 跳跃按离地、上升、最高点、下落、落地连续插值，增加两套交替持刀动作、双膝弯曲、空中伸展和落地压缩。空中使用技能时保留空中腿部姿态。
- 三类技能使用独立姿态时间线：回旋挥击、低身拔刀突进、双手举刀下劈；远程武器区分高位瞄准、低姿滑步和终极技架势，狩猎笛治疗使用演奏动作。
- 太刀登龙斩、操虫棍降龙从地面发动时会真正跃起，下落阶段结算命中；起跳可被翻滚取消。技能冷却、素材和存档格式保持兼容。
- 手臂与武器握点同步移动，刀光随握点、身体和朝向变化。地面阴影不再随猎人升空。
- 普通技能动作时长：技能一 0.62 秒，技能二 0.58 秒；终极技 1.05 秒，留出辨识起手与下劈的时间。
- [动作预览页](https://kamura-pixel-hunt-2dmh.soundloach9.chatgpt.site/motion-preview.html)：可切换 14 种武器、镜像朝向、半速播放。独立演示不读取或写入游戏存档。
