# 神火猎记 Implementation Plan

**Goal:** 交付可以创建角色、战斗、掉落、强化和存档的横版像素游戏。

**Architecture:** 无运行时依赖的 Canvas 游戏。数据、经济模型、战斗模拟、像素渲染、界面分离。

**Tech Stack:** ES modules / Canvas 2D / CSS / node:test。

**Spec:** 游戏设计方案.md

## Global Constraints

所有招式与数值为独立简化设计。支持键盘和触控。不使用外部图片依赖。存档只在当前浏览器保存，支持备份。胜利结算只可发生一次。
